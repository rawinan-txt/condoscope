# User Flow — CondoScope

```mermaid
flowchart TD
    A([เปิดเว็บ]) --> B[หน้าแรก<br/>ช่องค้นหา + ทำเลยอดนิยม + การ์ดโครงการ]
    B -->|พิมพ์ชื่อ/ทำเล หรือตั้งตัวกรอง| C[หน้าผลการค้นหา<br/>ตัวกรอง + เรียงลำดับ + การ์ด]
    B -->|คลิกการ์ดโครงการแนะนำ| D

    C -->|คลิกการ์ด| D[หน้าโครงการ<br/>แกลเลอรี ราคา สิ่งอำนวยความสะดวก ห้องว่าง]
    C -.->|ดูบนแผนที่ (ส่งตัวกรองต่อ)| M
    M -->|คลิกหมุด → popup → ดูโครงการ| D
    D -->|ปุ่ม เลือกห้องจากตัวอาคาร| E[Building Explorer 3D<br/>หมุน/ซูม · hover tooltip · โหมดสถานะ · ผ่าชั้น]
    E -->|คลิกห้อง| F[แผงรายละเอียดห้อง]
    E -.->|เลือกจาก Unit List / Floor Selector| F
    F -->|ดูรายละเอียด| G[หน้า Unit Detail<br/>แปลน + hotspot + ภาพภายใน]
    F -.->|จองห้องนี้ Demo| H[สถานะเป็น คุณจอง Demo<br/>เก็บในเบราว์เซอร์]
    G -->|กลับไปเลือกห้องอื่น| E
    G -.->|จองห้องนี้ Demo| H

    E -. เครื่องไม่รองรับ WebGL .-> E2[ภาพตึก 2D SVG<br/>ฟีเจอร์เหมือนเดิม]
    B -. API ล่ม .-> FB[[ทุกหน้าใช้ข้อมูลสำรอง<br/>+ แถบ Demo Fallback Mode]]
```

## จุดที่ต้องทดสอบตามเส้นทาง
1. **หน้าแรก → ค้นหา → โครงการ → ตึก → ห้อง → กลับไปตึก** ต้องเดินครบได้โดยไม่ติด (TC-090)
2. ทุกหน้าที่เปิดลิงก์ตรงหรือกดรีเฟรช ต้องไม่ขึ้น 404 (TC-091)
3. ปุ่ม Back ของเบราว์เซอร์ต้องพากลับหน้าก่อนหน้าได้ถูกต้อง (TC-092)
