# User Stories — CondoScope

ผู้ใช้หลัก (persona): **ผู้ที่กำลังหาซื้อคอนโด** อายุ 25–40 ปี ทำงานในกรุงเทพฯ หรือปริมณฑล มีงบและทำเลในใจ อยากดูห้องจริงให้ได้มากที่สุดก่อนไปชมโครงการ

รูปแบบ acceptance criteria: **Given** (สถานการณ์) / **When** (การกระทำ) / **Then** (ผลที่ต้องได้)

---

## Epic A — ค้นหาโครงการ

### US-01 ค้นหาจากหน้าแรก `REQ-01, REQ-02`
**ในฐานะ**ผู้หาซื้อคอนโด **ฉันอยาก**เริ่มค้นหาได้ทันทีที่เปิดเว็บ **เพื่อ**ไม่เสียเวลาหาว่าต้องเริ่มตรงไหน
- **Given** ฉันเปิดหน้าแรก **Then** ช่องค้นหาเป็นจุดเด่นที่สุดในส่วนบนของหน้า และไม่มีแผนที่เต็มจอหรือตึก 3D ขึ้นมาก่อน
- **Given** ฉันพิมพ์ชื่อโครงการหรือย่าน (เช่น "อารีย์") **When** กดค้นหา **Then** ไปหน้าผลการค้นหาที่แสดงเฉพาะโครงการที่ตรง
- **Given** ฉันกดปุ่มลัดทำเล **Then** ได้ผลการค้นหาของทำเลนั้นทันที

### US-02 กรองตามงบและทำเล `REQ-02, REQ-03`
**ในฐานะ**ผู้ซื้อที่มีงบจำกัด **ฉันอยาก**กรองตามจังหวัด เขต ช่วงราคา และจำนวนห้องนอน **เพื่อ**เห็นเฉพาะโครงการที่ซื้อไหว
- **Given** ฉันตั้งราคา 2–5 ล้านบาท **Then** ทุกการ์ดในผลลัพธ์มีราคาเริ่มต้นอยู่ในช่วงนั้น
- **Given** ตัวกรองไม่ตรงกับโครงการไหนเลย **Then** เห็นข้อความว่าไม่พบผลลัพธ์ พร้อมทางเลือกให้ล้างตัวกรอง
- **Given** ฉันเรียงตามราคา **Then** การ์ดเรียงถูกต้องจากน้อยไปมากหรือมากไปน้อย
- **Given** ฉันใช้มือถือ **Then** ตัวกรองเปิดเป็นแผงเลื่อนได้ และไม่บังผลลัพธ์จนใช้งานไม่ได้

### US-03 สำรวจบนแผนที่ `REQ-04`
**ในฐานะ**ผู้ซื้อที่สนใจทำเล **ฉันอยาก**เห็นโครงการบนแผนที่ **เพื่อ**ดูว่าใกล้ที่ทำงานหรือรถไฟฟ้าไหม
- **Given** ฉันอยู่ที่หน้าผลการค้นหา **When** กด "ดูบนแผนที่" **Then** แผนที่แสดงหมุดตามตัวกรองเดิม
- **When** คลิกหมุด **Then** เห็น popup ชื่อโครงการ ทำเล ราคาเริ่มต้น และลิงก์ไปหน้าโครงการ
- **Given** โหลดแผนที่ไม่สำเร็จ **Then** ยังเห็นรายการโครงการ พร้อมข้อความแจ้งว่าแผนที่ใช้งานไม่ได้
- **Then** มี attribution ของผู้ให้บริการแผนที่ให้เห็นตลอด

## Epic B — ดูโครงการและเลือกห้อง

### US-04 ดูรายละเอียดโครงการ `REQ-05`
**ในฐานะ**ผู้ซื้อ **ฉันอยาก**เห็นภาพรวมของโครงการ **เพื่อ**ตัดสินใจว่าควรดูห้องต่อไหม
- **Then** หน้าโครงการมีแกลเลอรี ชื่อ ทำเล ราคาเริ่มต้น สิ่งอำนวยความสะดวก และจำนวนห้องว่างแยกตามประเภทห้อง
- **Then** มีปุ่ม "เลือกห้องจากตัวอาคาร" เด่นชัด

### US-05 เลือกห้องจากตัวตึก (ฟีเจอร์หลัก) `REQ-06, REQ-07, REQ-08, REQ-23`
**ในฐานะ**ผู้ซื้อ **ฉันอยาก**ชี้หรือคลิกห้องบนตัวตึกได้โดยตรง **เพื่อ**รู้ว่าห้องอยู่ชั้นไหน หันทิศไหน และวิวเป็นยังไง
- **Given** ฉันเปิด Explorer **Then** เห็นทุกทาวเวอร์ของโครงการ หมุนและซูมได้
- **When** ชี้เมาส์ที่ห้อง **Then** ห้องนั้นไฮไลต์ และ tooltip แสดงเลขห้อง ชั้น ราคา พื้นที่ ห้องนอน ห้องน้ำ และสถานะ
- **When** คลิกห้อง **Then** แผงรายละเอียดแสดง**ข้อมูลของห้องที่คลิกจริงๆ** (เลขห้องต้องตรงกับห้องที่คลิก)
- **Then** ทุกโครงการทั้ง 5 โครงการเปิด Explorer ได้

### US-06 หาห้องตามเงื่อนไขบนตึก `REQ-10, REQ-11, REQ-12`
**ในฐานะ**ผู้ซื้อ **ฉันอยาก**เห็นว่าห้องไหนว่างและตรงงบ **เพื่อ**ไม่ต้องคลิกไล่ทีละห้อง
- **When** เปิดโหมดสถานะ **Then** ห้องแยกสีตามสถานะ และมีคำอธิบายที่เป็นตัวหนังสือด้วย ไม่ใช้สีอย่างเดียว
- **When** ตั้งตัวกรองราคาหรือจำนวนห้องนอน **Then** เฉพาะห้องที่ตรงเงื่อนไขสว่างขึ้น
- **When** เลือกชั้น **Then** ชั้นที่อยู่เหนือขึ้นไปหายไป และเห็นผังห้องทั้งชั้นจากด้านบน
- **Then** มีรายการห้องกับตัวเลือกชั้นให้เลือกห้องที่มองไม่เห็นจากภายนอกได้

### US-07 ใช้ Explorer ด้วยคีย์บอร์ดหรือจอสัมผัส `REQ-09, REQ-18, REQ-22`
**ในฐานะ**ผู้ใช้ที่ไม่ใช้เมาส์ **ฉันอยาก**เลือกห้องได้ด้วยคีย์บอร์ดหรือนิ้ว **เพื่อ**ใช้งานได้เท่าคนอื่น
- **Given** เลือกห้องอยู่ **When** กดลูกศร **Then** เลื่อนไปห้องข้างๆ หรือชั้นบนล่าง และ Enter เปิดรายละเอียด
- **Given** ใช้มือถือ **When** แตะห้อง **Then** เลือกห้องได้ และแผงรายละเอียดขึ้นจากด้านล่าง
- **Then** ปุ่มทุกปุ่มมีกรอบ focus ให้เห็นเมื่อกด Tab

### US-08 ใช้งานได้แม้เครื่องไม่รองรับ 3D `REQ-13`
**ในฐานะ**ผู้ใช้เครื่องรุ่นเก่า **ฉันอยาก**ยังเลือกห้องได้ **เพื่อ**ไม่ถูกตัดออกจากฟีเจอร์หลัก
- **Given** เบราว์เซอร์ไม่รองรับ WebGL **Then** เห็นภาพด้านหน้าตึกแบบ 2D ที่ hover, คลิก และดูสถานะได้เหมือนเดิม

## Epic C — ดูห้องและจอง

### US-09 ดูรายละเอียดห้องและภาพภายใน `REQ-15, REQ-19`
**ในฐานะ**ผู้ซื้อ **ฉันอยาก**เห็นแปลนและภาพภายในห้อง **เพื่อ**นึกภาพการอยู่จริงออก
- **Then** หน้าห้องแสดงเลขห้อง ชั้น ราคา พื้นที่ ห้องนอน ห้องน้ำ ทิศ และสถานะ
- **When** คลิกจุดบนแปลน (เช่น ห้องนอน) **Then** ภาพเปลี่ยนเป็นห้องนั้น และจุดที่เลือกมีสัญลักษณ์บอกว่ากำลังดูอยู่
- **Then** ภาพมีป้าย "ภาพประกอบสร้างด้วย AI"
- **Then** มีปุ่มกลับไปที่ตึกเพื่อเลือกห้องอื่น

### US-10 จองห้องแบบสาธิต `REQ-14`
**ในฐานะ**ผู้ซื้อที่สนใจห้อง **ฉันอยาก**กดจองห้อง **เพื่อ**เห็นว่ากระบวนการจองทำงานยังไง
- **Given** ห้องสถานะว่าง **When** กด "จองห้องนี้ (Demo)" **Then** สถานะห้องบนตึกเปลี่ยนเป็น "คุณจอง (Demo)" ทันที
- **Given** ห้องไม่ว่าง **Then** ปุ่มจองกดไม่ได้ และบอกเหตุผล
- **When** รีเฟรชหน้า **Then** การจองยังอยู่ในเบราว์เซอร์นี้ และยกเลิกได้
- **Then** ระบบไม่ขอชื่อ เบอร์โทร หรืออีเมล และบอกชัดว่าเป็นการสาธิต

## Epic D — ความน่าเชื่อถือ

### US-11 เว็บยังใช้ได้เมื่อเซิร์ฟเวอร์ล่ม `REQ-16`
**ในฐานะ**ผู้เยี่ยมชม portfolio **ฉันอยาก**ให้เว็บเปิดได้เสมอ **เพื่อ**ยังเห็นผลงานได้แม้ backend ฟรีมีปัญหา
- **Given** API ใช้งานไม่ได้ **Then** หน้าแรก แผนที่ และ Explorer ยังทำงานด้วยข้อมูลสำรอง
- **Then** มีแถบแจ้ง "Demo Fallback Mode" และไม่อ้างว่าเป็นข้อมูล live

### US-12 รู้ว่าข้อมูลเป็นของจำลอง `REQ-19`
**ในฐานะ**ผู้เยี่ยมชม **ฉันอยาก**รู้ชัดว่าไม่มีการขายจริง **เพื่อ**ไม่เข้าใจผิด
- **Then** ทุกหน้ามีข้อความ "ข้อมูลจำลองเพื่อการสาธิต ไม่มีการขายจริง"
